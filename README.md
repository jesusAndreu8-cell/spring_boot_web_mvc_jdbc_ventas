# spring_boot_web_mvc_jdbc_ventas

Proyecto Spring Boot (Maven, Java 21) con JdbcTemplate sobre la BD `ventas`.

- `ClienteDAO` y `ComercialDAO` (interfaz + implementación con JdbcTemplate).
- Pruebas por arranque con `CommandLineRunner` en `SpringBootWebMvcJdbcVentasApplication`.
- La BD se crea con `ventas.sql`.
